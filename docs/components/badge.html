Badge

Labels, counts, or status indicators.

Usage

<!-- Default -->
<span x-data="badge()" x-bind="badgeAttrs">Badge</span>

<!-- Outline -->
<span x-data="badge({ variant: 'outline' })" x-bind="badgeAttrs">Outline</span>
