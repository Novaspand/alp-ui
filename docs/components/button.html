Button

Displays a button or a component that looks like a button.

Installation

<!-- alp-ui.js MUST come before Alpine.js -->
<script defer src="https://cdn.jsdelivr.net/gh/novaspand/alp-ui/dist/alp-ui.js"></script>
<script defer src="https://cdn.jsdelivr.net/npm/alpinejs@3.x.x/dist/cdn.min.js"></script>

Usage

<!-- Pass variant and size as props -->
<button x-data="button({ variant: 'default', size: 'default' })" x-bind="buttonAttrs">
  Button
</button>

<!-- Outline variant, large size -->
<button x-data="button({ variant: 'outline', size: 'lg' })" x-bind="buttonAttrs">
  Large Outline
</button>

Examples

Size

Use different size classes to change the button size.

<!-- xs -->
<button x-data="button({ size: 'xs' })" x-bind="buttonAttrs">xs</button>

<!-- sm -->
<button x-data="button({ size: 'sm' })" x-bind="buttonAttrs">sm</button>

<!-- default -->
<button x-data="button()" x-bind="buttonAttrs">default</button>

<!-- lg -->
<button x-data="button({ size: 'lg' })" x-bind="buttonAttrs">lg</button>

Default

<button x-data="button()" x-bind="buttonAttrs">Button</button>

Secondary

<button x-data="button({ variant: 'secondary' })" x-bind="buttonAttrs">Secondary</button>

Destructive

<button x-data="button({ variant: 'destructive' })" x-bind="buttonAttrs">Destructive</button>

Outline

<button x-data="button({ variant: 'outline' })" x-bind="buttonAttrs">Outline</button>

Ghost

<button x-data="button({ variant: 'ghost' })" x-bind="buttonAttrs">Ghost</button>

Link

<button x-data="button({ variant: 'link' })" x-bind="buttonAttrs">Link</button>

Icon

<!-- icon-sm -->
<button x-data="button({ size: 'icon-sm' })" x-bind="buttonAttrs">
  <svg ...></svg>
</button>

<!-- icon (default) -->
<button x-data="button({ size: 'icon' })" x-bind="buttonAttrs">
  <svg ...></svg>
</button>

<!-- icon-lg -->
<button x-data="button({ size: 'icon-lg' })" x-bind="buttonAttrs">
  <svg ...></svg>
</button>

With Icon

<!-- Icon at start -->
<button x-data="button()" x-bind="buttonAttrs">
  <svg class="mr-2" ...></svg>
  Upload
</button>

<!-- Icon at end -->
<button x-data="button()" x-bind="buttonAttrs">
  Next
  <svg class="ml-2" ...></svg>
</button>

Rounded

Add rounded-full to the element or use class prop.

<button x-data="button({ class: 'rounded-full' })" x-bind="buttonAttrs">Get Started</button>

Loading

Toggle a loading state with a spinner icon.

<button x-data="button()" x-bind="buttonAttrs" :disabled="loading">
  <svg x-show="loading" class="mr-2 size-4 animate-spin" ...></svg>
  <span x-text="loading ? 'Loading...' : 'Click me'"></span>
</button>

Disabled

<!-- Add the disabled attribute -->
<button x-data="button()" x-bind="buttonAttrs" disabled>Primary</button>

Rounded

Use rounded: true for pill-shaped buttons.

<!-- Add rounded: true for pill shape -->
<button x-data="button({ rounded: true })" x-bind="buttonAttrs">Rounded</button>
<button x-data="button({ variant: 'outline', rounded: true })" x-bind="buttonAttrs">Outline</button>
<button x-data="button({ size: 'icon', variant: 'outline', rounded: true })" x-bind="buttonAttrs">
  <svg ...></svg>
</button>

API Reference

Prop Type Default
variant "default" | "secondary" | "destructive" | "outline" | "ghost" | "link" "default"
size "xs" | "sm" | "default" | "lg" | "icon" | "icon-sm" | "icon-lg" "default"
rounded boolean false
