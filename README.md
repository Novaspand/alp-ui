# alp-ui

Framework-agnostic shadcn/ui component library built on Alpine.js and Tailwind CSS. No build step required.

```html
<!-- Add to your HTML -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/novaspand/alp-ui@main/dist/ui.css">
<script defer src="https://cdn.jsdelivr.net/npm/alpinejs@3.x.x/dist/cdn.min.js"></script>
```

Optional theme:
```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/novaspand/alp-ui@main/dist/themes/rose.css">
```

Works in plain HTML, Django templates, Rails ERB, PHP, HTMX — any server-rendered stack.

## Status

Early development. Components are being built.

## Development

```bash
npm install
npm run build     # build dist/
npm run dev       # watch mode
```
